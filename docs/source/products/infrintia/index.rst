Infrintia
=========

Infrintia is CrossGL's decentralized GPU compute marketplace. It connects
developers who need on-demand model inference with hosts that can sell idle GPU
capacity through a broker API, Python SDK, and host agent.

The broker reserves credits, routes work to a compatible host, streams tokens
back to the client, finalizes billing, and refunds unused reservations on
failure or cancellation.
