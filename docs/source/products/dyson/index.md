# Dyson

Dyson is CrossGL's compute routing and serverless execution package. It analyzes Python, NumPy, JAX, TensorFlow, PyTorch, and C++ workloads, then routes execution to configured compute targets based on cost, latency, hardware affinity, and optimization intent.

This page is the central site entry point for Dyson. The Dyson repository owns the detailed API reference and service internals generated from its local Sphinx and Doxygen configuration.
